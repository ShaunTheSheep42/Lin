# Lin

## 简介

全键盘非线性编辑的伪TUI文本编辑器

全键盘: 无鼠标, 仅使用键盘
非线性编辑: 可在画布上任意处往任意方向编辑成任意结构
伪TUI: 用GUI模拟TUI

版本: 0.1.0
许可: LGPL

## 特色

- 专注当前屏幕
  通过人为规划(分类并链接)将文本内容成固定在一个屏幕能全部显示的大小
  从而无需移动画布编辑当前屏幕外的内容
- 视觉信息
  保持文本信息与文本结构一致
  适合实现各种信息结构(图, 树, 表)
- TUI与全键盘
  全键盘操作, 避免切换开销
  全文本语义, 避免富文本繁琐操作
- 语义块
  块(Block)有语义, 可使用python编程
  执行语义可以直接运行python代码

## 功能描述

### 相关概念

#### 画布(Canvas)

38*128个单元格的集合
画布大小随着单元格的大小改变(即随着字体的大小而改变)
(注意: 整个窗口即画布, 没有任何文件树, 状态栏等内容)

#### 单元格

画布上的最小显示单位
半角字符占一个单元格, 全角字符占两个单元格(分别是字符与占位符)
1个单元格为矩形, 2个单元格为正方形

#### 块(Block)

块为一块由(单/多)行且无空行(即连续)组成的区域
块不可与任何块的任何部分重叠
在插入模式下, 由于被修改的块大小不确定, 因此运行其能短暂地覆盖在其他块上面
在退出插入模式时, 如果其依旧与其他块重叠
那么按下esc不会保存修改进入normal模式
而是直接进入Visual模式, 并处于选中当前块的状态
此时需操作(移动/删除等)块让其不会和任何块重叠
否则无法回到Normal模式

(注意! 重叠时, 半角遮挡住全角时, 全角会被全部遮挡)

#### 组(Group)

每个块都属于一个组
多个块在画布上形成区域voronoi图
一个组由一个分区中的各个块组成

## 使用

### 交互原则

- 所有操作应通过键盘完成, 无鼠标
- 采用配置文件进行配置(使用python进行配置)

### 操作

#### 模式

- Normal 操作文本
- Insert 插入文本
- Visual 选区并操作
  - 普通Visual
  - 行Visual
  - 区域Visual(就是vim的块选择, 只不过这里由于重名所以改名叫区域)
- Lin 操作块(执行语义代码, 移动/删除/复制块)

#### 键盘

输入事件定义见 [input-events.md](./input-events.md)，命令语法见
[syntactic.bnf](./syntactic.bnf)，模式转换见
[editor-state.md](./editor-state.md)，命令语义见
[command-semantics.md](./command-semantics.md)，文档不变量见
[document-invariants.md](./document-invariants.md)。

### 配置

- 配置文件配置(配置文件位置在$HOME/.config/lin/config.py)
- 配置内容包括但不限于
  - 键位映射
  - ".lin"文件查找位置

### 存储与文件格式

- 采用json存储整个画布内容, 一个json文件对应一个文件画布
  该文件后缀为".lin", 经过压缩
  格式保存文档, 包含画布元数据, 块列表(位置, 大小等)
  资源索引位置(图片/音视频)和版本信息
  注意: 资源应和".lin"文件位于同一目录下, 不支持任何其他目录位置
- 版本策略: 大版本可能会不兼容, 小版本一定会兼容

### 扩展性与插件

- 提供插件接口(python 插件)
- 明确定义插件 API 的生命周期与安全边界(避免主进程崩溃)

### 无障碍与国际化

- 不支持无障碍(未来也不支持)
- 目前仅支持中文和英文两种语言, 暂不考虑支持其他语言

### 测试策略

- 单元测试: 核心库(文档, 块, 坐标计算等)
  使用 QT 测试框架(QT Test)
- 性能测试: 记录帧时间, 内存与资源加载时间, 使用基准场景回归检测
- 集成测试: 启动最小化 UI 并运行关键路径(加载/保存/编辑/渲染快照)
  自动化测试
